# DiskLens WPF 1.0.13

Buttons now use theme-controlled normal, hover and pressed backgrounds, preserving each button's text and icon foreground. This fixes the default Windows pale hover background behind light text in dark mode. Keyboard focus remains visible and disabled buttons remain distinct.

Validation: WPF UI suite with actual parent-button hover state, rendered dark/light screenshots and measured label/background contrast of at least 4.5:1.
