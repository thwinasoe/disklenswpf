# DiskLens WPF 1.0.14

Folder lists now use a quiet, borderless presentation with a consistent background, subtle hover and selection, larger labels, vertically aligned values, and more comfortable row spacing. Relative-size bars show only the occupied portion, with no full-width empty track. Small files no longer create heavy horizontal lines. Name columns stay within a readable width on wide windows. Compact density remains available and keyboard focus stays visible.
