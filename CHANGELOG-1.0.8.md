# DiskLens WPF 1.0.8

Investigation queries show a slim animated indeterminate progress bar beneath their status, including while comparing completed indexes. No percentage is fabricated. The bar hides when the current request succeeds, fails, has no compatible baseline, is superseded, or the user leaves Investigate. Older cancelled requests cannot clear the loading state of a newer request. Duplicate verification and live health retain their existing status workflows.

Release build and actual WPF UI regressions verify pending state, completion and navigation cancellation. Read-only verification against saved snapshots captures the progress bar while comparing and the populated results after completion. Existing scans and Electron remain unchanged.
